# Laboratórios de Redes — Cisco Packet Tracer

Repositório criado para documentar meus estudos práticos de **Redes de Computadores** utilizando o **Cisco Packet Tracer**.

Os laboratórios apresentados aqui têm como objetivo desenvolver conhecimentos sobre infraestrutura de redes, dispositivos de comunicação, conectividade e diagnóstico de problemas de rede.

---

##  Objetivo

Neste laboratório foi simulada uma **rede doméstica** utilizando diferentes dispositivos de rede e equipamentos presentes em uma infraestrutura residencial.

A atividade permite visualizar como diferentes dispositivos podem se conectar à rede e como o roteador atua como um dos principais elementos de comunicação da infraestrutura.

## Topologia

A topologia contém dispositivos como:

-  Roteador wireless
-  Cable Modem
-  Cable Splitter
-  Computador
-  Notebook
-  Smart TV
-  Computador do quarto
-  Conexão com a Internet
